# sar — testing single-image "SAR Doppler tomography"

Simulation and analysis code behind **[Doppler Tomography, Tested](https://ejhong.github.io/sar/)**: a reproducible
test of the single-SLC "Doppler tomography" method used by Biondi & Malanga (2022, retracted 2026) and by the
2025 Khafre "underground city" announcement.

The idea is simple. Reimplement the published pipeline exactly as described (Doppler sub-aperture pairs,
32 × 32 patch cross-correlation, steering-matrix "depth" focusing), then feed it synthetic scenes whose
contents are known: a motionless stepped pyramid, empty desert, two rocks, a wall of courses, a patch of
ground that really vibrates. Whatever the pipeline draws at depth cannot be geology.

## Layout

```
sarsim/        the toolkit
  geometry.py  radar geometry; Doppler <-> slow time <-> baseline <-> aspect; the Kz steering wavenumber
  scene.py     scatterer scenes: stepped pyramid with layover/occlusion/flash, rocks, vibrating patches
  synth.py     spectral-domain synthesis of a focused SLC from point scatterers (+ speckle clutter)
  subap.py     reference/offset Doppler sub-aperture bank (K pairs, B_shift, bin snapping, taper)
  track.py     batched complex cross-correlation with upsampled-DFT sub-pixel refinement
  tomo.py      trajectory -> depth: paper variant |a(z)^H Y|^2 and replication variant (W=25 adjusted R^2)
  pipeline.py  end-to-end run
  viz.py       figure styling
experiments/   one script per test (t01 ... t06); each writes results/<test>/summary.json + figs/
results/       summaries and figures (cache/ holds large arrays and is not committed)
docs/          the GitHub Pages site, generated by build_site.py
tests/         pytest unit tests for the synthesizer, tracker and focusing
```

## Run

```
python3.11 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m pytest tests
cd experiments && ../.venv/bin/python t01_static_pyramid.py   # ~5 min; t02 ... t06 likewise
cd .. && .venv/bin/python build_site.py                        # regenerates docs/index.html
```

Adding a test: write `experiments/tNN_name.py` that saves figures and a `summary.json` with the keys
`id, order, tag, eyebrow, title, question, finding, limitations, method, figures, metrics`, then rebuild.
