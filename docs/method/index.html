Method and sources

Everything on this site is generated from the repository by code anyone can run: the compositions from their JSON, the simulations from their scripts, the figures and volumes from the runs that made them. Nothing is edited by hand, and every number carries its source or is marked as assumed.

Two commands rebuild everything

cd sim && uv sync && uv run pytest        # the simulation and its checks
uv run python -m katabasis.export          # everything the site reads
cd ../web && npm ci && npm run build        # the site, into docs/

One repository, three parts

sites/

The materials library and one composition per site, shared by the simulation and the viewer.

sim/

The Python lab: compositions, the elastic solver, the arrays and inversions, and the first investigation kept intact in sim/legacy/.

web/

This site: Astro and Three.js, hand-drawn figures, no chart library. Source · first investigation
